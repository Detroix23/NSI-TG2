# NSI Architecture: System-on-Chip.
Synthèse.

## Architecture Von-Neumman.
Architecture "classique":
- **Central Process Unit**:
    - coeurs;
    - fréquence;
    - _threads_;
    - cache;
- **Random Access Memory**;
- **Graphic Processing Unit**;
- **Motherboard**;
- **Modem**;
    - WiFi;
    - Bluetooth;
    - Near-Field Communication;
    - réseaux mobiles (3G, 4G, 5G).
- **Digital Signal Processor**;
- **Image Signal Processor**;
- **Secure Processing Unit**;
- **Neuronal Processing Unit**.

## System-on-a-Chip.

**Fabricants**:
- AMD;
- Apple;
- Broadcom;
- Intel;
- Nvidia;
- Qualcomm;
- Samsung;
- Texas Instrument.

**Avantages**:
- taille miniaturisée et légèreté;
- multi-tâche;
- efficient (en énergie);
- circulation des données accrue;
- faible coût financier.

**Désavantages**:
- customization nulle.
